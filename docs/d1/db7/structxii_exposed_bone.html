xiiResult xiiExposedBone::ComputeParentTransforms ( xiiArrayPtr< const xiiExposedBone > bones,
xiiDynamicArray< xiiMat4 > & out_parentTransforms )
static

Computes each bone's parent-to-model matrix in input order, allowing unsorted and disconnected hierarchies. Empty parent names denote roots. Empty/duplicate names, missing parents, cycles, and non-finite transforms fail and clear out_parentTransforms. Uses O(n) expected time and O(n) scratch memory without recursion. Any asset import/root transform is applied by the consumer, outside these local bone transforms.
