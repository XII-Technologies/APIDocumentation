Detailed Description

Backend-independent owner for sparse bindless descriptor tables.

Resources remain strongly referenced after Retire() until Collect() observes the last-use fence. The descriptor and its stable index therefore cannot alias while an older command list is still executing. A table can be rebound to every command list because only occupied slots are emitted by descriptor-indexing backends.
