Detailed Description

Validate native animation graph authoring before publishing a runtime resource. The source is never modified. Failure clears the output and reports the first structural error. Aliased input/output is rejected without modifying either. Pose dependencies must be acyclic, including disconnected nodes. Evaluation depth is limited to 128 because the current runtime evaluates recursively. Transitions retain their authored order, which determines priority at runtime.
