◆ ApplyAssetProfiles()

xiiStatus xiiAssetCurator::ApplyAssetProfiles ( xiiArrayPtr< const xiiPlatformProfile *const > profiles,
xiiUInt32 uiActiveProfile )

Persists and publishes a complete profile collection in the supplied order. Index zero must be Default. The input is cloned; ownership is retained by the caller. Must be called on the main thread between asset operations. Stops processor jobs and hashing during publication. A failed file installation rolls back previously installed files and leaves live profiles unchanged. Rollback failures are reported with retained backup paths. This is not a crash-safe transaction across files. Successful publication invalidates all existing profile pointers.

◆ ClearAssetCaches()

void xiiAssetCurator::ClearAssetCaches ( xiiAssetDocumentManager::OutputReliability threshold)

Deletes all files in all asset caches, except for the asset outputs that exceed the threshold.

-> OutputReliability::Perfect -> deletes everything -> OutputReliability::Good -> keeps the 'Perfect' files -> OutputReliability::Unknown -> keeps the 'Good' and 'Perfect' files

◆ FindSubAsset()

const xiiAssetCurator::xiiLockedSubAsset xiiAssetCurator::FindSubAsset ( xiiStringView sPathOrGuid,
bool bExhaustiveSearch = false ) const

Tries to find the asset information for an asset identified through a string.

The string may be a stringyfied asset GUID or a relative or absolute path. The function will try all possibilities. If no asset can be found, an empty/invalid xiiAssetInfo is returned. If bExhaustiveSearch is set the function will go through all known assets and find the closest match.

◆ GenerateTransitiveHull()

void xiiAssetCurator::GenerateTransitiveHull ( const xiiStringView sAssetOrPath,
xiiSet< xiiString > & inout_deps,
bool bIncludeTransformDeps = false,
bool bIncludeThumbnailDeps = false,
bool bIncludePackageDeps = false ) const

Generates one transitive hull for all the dependencies that are enabled. The set will contain dependencies that are reachable via any combination of enabled reference types. Resolves asset paths and sub-assets to their owners for traversal. Unresolved references remain in the output as leaves. Existing output does not suppress traversal. Cycles are visited once per owner.

◆ ReloadAssetProfiles()

xiiResult xiiAssetCurator::ReloadAssetProfiles ( )

Reloads changed profile definitions from disk, preserving the active profile by name. Must be called between asset operations on the main thread. Stops background hashing before replacing profiles; all previously obtained profile pointers are invalidated on change. Invalid input leaves the current definitions and active profile unchanged.
