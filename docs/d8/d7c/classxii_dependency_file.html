Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

This class represents a set of files of which one wants to know when any one of them changes.

xiiDependencyFile stores a list of files that are the 'dependency set'. It can be serialized. Through HasAnyFileChanged() one can detect whether any of the files has changed, since the last call to StoreCurrentTimeStamp(). The time stamp that is retrieved through StoreCurrentTimeStamp() will also be serialized.
