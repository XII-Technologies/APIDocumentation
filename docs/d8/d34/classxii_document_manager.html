◆ EnsureDocumentIsClosed()

bool xiiDocumentManager::EnsureDocumentIsClosed ( xiiStringView sPath)

If the given document is open, it will be closed. User is not asked about it, unsaved changes are discarded. Returns true if the document was open and needed to be closed. This function only operates on documents opened by this manager. Use EnsureDocumentIsClosedInAllManagers() to close documents of any type.

Constructs a document, including its initial content. On failure the manager destroys any returned document. A successful factory must return a non-null document. Loading, registration and window events follow only on success.
