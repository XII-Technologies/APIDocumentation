Detailed Description

Calibrated camera and detector response used by robotics and scientific views.

Focal length and principal point use pixel units so recorded calibration data can be transferred without conversion. Distances are metres, exposure is seconds and wavelength is nanometres. Spectral sensitivity converts scene RGB radiance into a scalar detector response for infrared, depth-return and LiDAR modes.
