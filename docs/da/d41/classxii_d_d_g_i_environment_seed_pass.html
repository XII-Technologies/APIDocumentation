Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Budgeted analytic sky/sun probe seeding, preserving the existing non-RT baseline. It is an explicit algorithm; it is never selected as a fallback for a missing ray-tracing pipeline.
