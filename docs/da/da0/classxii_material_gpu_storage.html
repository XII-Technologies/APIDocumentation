Detailed Description

Central, generation-checked material buffer allocator.

Material resources no longer allocate one constant buffer each. Instances receive stable slots in a large shader-resource buffer, and only revisions missing from the current frame slice are uploaded. Retired slots are reused only after the caller reports their last-use frame complete.
