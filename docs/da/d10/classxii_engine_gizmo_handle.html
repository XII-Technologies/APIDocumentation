Detailed Description

A synchronized Editor handle, drawn through GraphicsCore debug batches and picked against the same CPU geometry and view transform. Owns no world objects, components, materials, or GPU resources. Access and global scale changes require exclusive Editor/engine-process access, as with other sync objects.
