Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Holds native rendering view data. Projection matrices use ZeroToOne reversed Z: near depth is one, far/background depth is zero. Core cameras retain conventional depth.

Copyright (c) Theophilus Eriata. All Rights Reserved.

Calculates the start position and direction (in world space) of the picking ray through the screen position in this view.

fNormalizedScreenPosX and fNormalizedScreenPosY are expected to be in [0; 1] range (normalized screen coordinates). The ray starts on the near plane and points into the scene. If no finite ray can be computed, XII_FAILURE is returned and outputs remain unchanged.
