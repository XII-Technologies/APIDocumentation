Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

GPU request table entry. Key is the complete geometry ID plus one; zero is an empty entry. One initialized frame table merges a geometry's requests toward the finest LOD and strongest priority. Entry zero stores raw, unique and overflow counts in Key, DesiredLod and Priority respectively.
