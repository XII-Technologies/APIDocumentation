Detailed Description

Serializes device-wide frame preparation and submission across rendering workloads. Begin acquires the rendering lock, waits for reusable frame slots, and advances the shared material/visibility/shadow/bindless timeline. End captures all submitted queues, including failed or empty frames, and releases the lock. Destruction calls End. Use on one thread; nesting fails.
