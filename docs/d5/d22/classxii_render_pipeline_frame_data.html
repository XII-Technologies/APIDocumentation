Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

An owned immutable setup snapshot exchanged through compiled data pins. Runtime values are never serialized as pipeline properties or document identities. A snapshot belongs to one graph setup; external inputs cannot retag older snapshots.
