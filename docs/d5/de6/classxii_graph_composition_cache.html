Detailed Description

Optional CPU composition cache, separate from graph storage and mutation. Synchronize access externally. Publishers must advance the appropriate revision when changing a definition; advance DefinitionRevision when replacing a document without finer change classification. Presentation changes are ignored. Instance parameter/override edits belong to their containing definition's Parameters/Resources/Topology revision, according to consumer semantics.
