Detailed Description

One mutable instance per pass per view. Constructors/Configure/GetPins must not access GAL. Build emits frame-specific work through the specialized render graph. Execute delegates must capture owned instance state or frame data, never this stack context. Instances remain alive until their graph execution has finished. Persistent GAL objects follow the device's deferred lifetime rules.
