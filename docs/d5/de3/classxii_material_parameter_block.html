Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Dense CPU representation of a material's typed values.

The byte block follows the schema's canonical GPU layout and can therefore be copied directly into structured or constant-buffer storage. Variants are retained for editor inspection and serialization, but never need to be searched by name during rendering.
