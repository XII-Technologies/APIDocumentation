Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Abstract interface for per-pass GPU timing instrumentation in the render graph.

Implement this interface to capture GPU performance data during render graph execution. The executor calls OnGraphBegin / OnGraphEnd around each queue submission command list, and OnPassBegin / OnPassEnd around each pass's RecordCommands call. OnFrameEnd is called after all passes have been submitted so implementations can schedule readback or finalize timing data.
