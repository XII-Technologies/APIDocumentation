Detailed Description

Shared, Qt-independent skeleton document model. Runtime resources contain only native joint / rest-pose data. Collider, constraint, import and preview settings remain authoring data until a runtime consumer supports them.

Member Function Documentation

◆ FillResourceDescriptor()

xiiResult xiiEditableSkeleton::FillResourceDescriptor ( xiiSkeletonResourceDescriptor & out_descriptor) const

Produces native parent-before-child joints, baking import coordinates into each root local pose. Rejects malformed hierarchies, duplicate / empty names and non-invertible or non-finite poses. Iterative conversion and destruction support deep hierarchies. Failure clears out_descriptor.

◆ MergeImportedHierarchy()

xiiResult xiiEditableSkeleton::MergeImportedHierarchy ( xiiEditableSkeleton & newSkeleton)

Copyright (c) Theophilus Eriata. All Rights Reserved.

Replaces the hierarchy with imported joints, preserving document settings and per-joint user properties by name. The document's import coordinates determine manipulator frames. Imported transforms and collider meshes win. Success transfers joint ownership and empties newSkeleton; failure leaves this document unchanged.
