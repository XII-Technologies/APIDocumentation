Detailed Description

Encapsulates a view on the given world through the given camera and rendered with the specified RenderPipeline into the given render target setup.

The view owns a generation-checked context for its rendering pipeline. Persistent GPU resources are stored by xiiViewRenderResourceManager so they are released before allocator and GAL shutdown regardless of world lifetime. A selected render pipeline resource populates the graph each frame.

Calculates the start position and direction (in world space) of the picking ray through the screen position in this view.

fNormalizedScreenPosX and fNormalizedScreenPosY are expected to be in [0; 1] range (normalized screen coordinates). If no ray can be computed, XII_FAILURE is returned.

Resolves an object ID produced by this view's native GPU scene to a live mesh owner. Call at a CPU frame boundary under world access. ◆ SetRenderEnabled()

Controls render-data extraction and graph execution by the owning world module. Disabled views retain their camera, targets, pipeline instance, and cached resources. This does not change IsValid(). Call InvalidateTemporalHistory() when resuming after a camera cut. Like other view mutations, this requires exclusive access to the owning world.
