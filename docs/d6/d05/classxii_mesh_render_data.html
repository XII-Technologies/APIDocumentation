Detailed Description

Renderer-facing packet for mesh draws.

The packet is deliberately meshlet/indirect friendly. Render passes can bind the mesh buffer resources directly, select sections/LODs on GPU, upload instance/skin/morph streams, and emit mesh shader or indexed fallback draws from the same data.

◆ RangeMode

enum class xiiMeshRenderData::RangeMode : xiiUInt8
strong

Meaning of the packet's range for residency-aware consumers. Indexed consumers continue to use the extracted CPU LOD range. Custom packets default to an exact primitive range, which must be meaningful in every LOD they allow. Component packets identify authored mesh sections so native scenes can select each LOD's own ranges/materials without assuming matching layouts.
