Detailed Description

Process-wide GPU emissive-light extraction service.

The service does not retain CPU mesh copies or duplicate scene registrations. Each graph build consumes the generation-bearing geometry table, frame-sliced scene instances, and canonical material table, then reconstructs world-space emissive triangles from bindless mesh buffers. Allocator-backed state exists only between GraphicsCore subsystem startup and shutdown. Configuration, graph construction and statistics are synchronized. Startup/shutdown and references returned by GetConfiguration() require callers to quiesce configuration changes.
