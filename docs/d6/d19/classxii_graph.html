Detailed Description

General directed multigraph, with stable, graph-owned handles and no domain-specific semantics. Parallel edges, loops, cycles and isolated vertices are supported. Lookup/degree/edge removal are O(1), insertion amortized O(1), vertex removal O(in + out), enumeration O(V + E). Adjacency allocates nothing.

Unrelated handles survive mutation and Reserve. Reacquire all views, dense indices and cursors after any mutation. Adjacency visits newest edges first; dense enumeration uses swap removal. Removed/foreign handles are rejected. Generations never wrap: exhausted slots retire. Compact explicitly remaps all live handles.

Concurrent const access is supported; use xiiSynchronizedGraph for synchronized mutation. Validators, event handlers and algorithm visitors must not mutate the graph. Instance subscriptions/validators remain with the graph object when topology is moved. CopyFrom provides explicit, recoverable copying and remapping.
