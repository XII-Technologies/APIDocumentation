Detailed Description

Process-wide virtual-shadow-map page residency service.

State is allocated by the GraphicsCore subsystem after Foundation startup, avoiding allocator use from global constructors. Owns device page allocations, CPU demand and residency metadata. Feedback and raster algorithms belong to selected pipeline resources. Access is serialized by the existing GPU frame owner.
