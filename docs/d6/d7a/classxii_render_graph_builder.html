Detailed Description

Declarative API used inside a pass's setup callback to declare resource usage.

Each call to Read* or Write* records a dependency edge in the graph's dependency table and advances the resource version on writes. The builder may only be used within the setup callback passed to xiiRenderGraph::AddPass().
