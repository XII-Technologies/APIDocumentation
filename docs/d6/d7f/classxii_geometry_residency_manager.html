Detailed Description

Static subsystem facade for the stable GPU geometry table and mesh LOD residency service.

Allocator-backed CPU state is created during core startup and GPU resources are created during high-level startup. Callers never construct, own, cache, or destroy a manager object.

◆ AcquireMeshGeometry()

xiiGeometryHandle xiiGeometryResidencyManager::AcquireMeshGeometry ( const xiiMeshResourceHandle & hMesh)
staticnodiscard

Acquires a shared residency record for an engine mesh resource. Multiple scene objects using the same content revision receive the same generation-checked geometry handle. Reloading publishes a new record; outstanding references retain the previous revision. Mesh LODs packed into one buffer are translated into reflected meshlet ranges by the subsystem. Call on the render thread, as with other residency mutations. Returns an invalid handle for unloaded data.

xiiResult xiiGeometryResidencyManager::GetPrimitiveRangeMeshletCounts ( xiiGeometryHandle handle,
xiiUInt32 uiFirstPrimitive,
xiiUInt32 uiPrimitiveCount,
xiiArrayPtr< xiiUInt32 > out_counts )
staticnodiscard

Counts meshlets overlapping a primitive range in each authored LOD, including unloaded LODs. A zero primitive count selects the entire LOD, matching GPU visibility. The output must have s_uiMaxLods entries and is cleared on failure. Reads source metadata in O(total meshlets); cache the result until the geometry handle or primitive range changes. Rejects reloaded source buffers belonging to a different revision. Call on the render thread.
