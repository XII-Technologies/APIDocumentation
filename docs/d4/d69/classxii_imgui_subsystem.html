Detailed Description

Subsystem-owned context registry. No contexts are created implicitly, and no worlds or views are retained. Context/input/texture registration operations run on the main thread. Immutable frames may be consumed by render setup/execution on other threads. Drain graphs and release snapshots before unloading the plugin.
