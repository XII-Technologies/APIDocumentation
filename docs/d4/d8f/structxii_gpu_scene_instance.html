Detailed Description

Canonical, backend independent GPU record. It deliberately contains both current and previous transforms so motion vectors never need a second scene lookup.

◆ m_NormalTransformRow0

xiiVec4 xiiGpuSceneInstance::m_NormalTransformRow0 = xiiVec4(1.0f, 0.0f, 0.0f, 0.0f)

Rows of the inverse-transpose upper 3x3. Keeping these in the instance record avoids recomputing an inverse per mesh vertex and produces correct normals under non-uniform scale.
