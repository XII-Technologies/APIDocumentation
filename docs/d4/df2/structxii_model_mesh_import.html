Detailed Description

Converts model files directly into native mesh descriptors. No scene/importer base classes or Qt. Each mesh instance becomes a section; referenced source materials map to shared material slots. Node/root transforms are baked into vertices, inverse-transpose normals and mirrored winding. Skinning uses a named mesh-local palette, up to four strongest influences per vertex, and native byte weights. The caller assigns the default skeleton resource and resolves material assets. Native packed vertices retain two UV sets and one color set; additional sets are rejected. Animated morph targets cannot be represented by the current native skinning path and are rejected. ReadFile clears output on failure and never exposes pointers into Assimp-owned storage.
