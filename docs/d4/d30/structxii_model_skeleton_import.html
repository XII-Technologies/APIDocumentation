xiiResult xiiModelSkeletonImport::ReadFile ( xiiStringView sSourceFile,
xiiModelSkeletonImport & out_import,
xiiStringBuilder * out_pError = nullptr )
static

Reads an absolute source filename using the existing Assimp dependency, including external glTF buffers. Preserves the complete named scene hierarchy in parent-before-child order and signed local TRS poses. UCX_<joint>[_suffix] mesh instances become joint-local convex authoring geometry. Duplicate / empty joint names, shear, non-finite or singular poses and invalid geometry fail explicitly. Conversion is iterative; format parsing and its limits belong to Assimp. Failure clears out_import.
