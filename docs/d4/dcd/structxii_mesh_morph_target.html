Detailed Description

Dense additive morph deltas in the mesh vertex buffer, using its native stream layout. The range supplies deltas for source vertices [0, count). Apply weighted deltas before skinning. Position/normal/tangent xyz are deltas; UVs and tangent handedness remain from the base vertex.
