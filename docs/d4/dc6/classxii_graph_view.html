Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Non-owning subset of one graph object. The source must outlive the view. No subscriptions or membership bookkeeping are added to the source, so source mutation costs are unchanged. Queries validate generations and current endpoints. Induced views include newly inserted edges between selected vertices; selected views include only explicitly selected edges. Enumeration follows source dense order and costs O(V + E). Reacquire enumerations after source mutation. Views stay with their source object when topology moves, just like graph subscriptions.
