Detailed Description

Immutable render packet extracted from an authored reflection capture.

The cubemap is expected to contain a full GGX pre-filter mip chain. Keeping filtering in the asset pipeline avoids repeating expensive convolution for static probes every frame while still allowing dynamic captures to replace the handle when their asynchronous convolution completes.
