Detailed Description

Default-device residency service for geometry pages, virtual texture tiles, and stable GPU tables.

Allocator-backed CPU state is created during core startup and GPU resources are created during high-level startup. Callers never construct, own, cache, or destroy a manager object.

◆ AcquireMeshGeometry()

xiiGeometryHandle xiiGpuResidencyManager::AcquireMeshGeometry ( const xiiMeshResourceHandle & hMesh)
staticnodiscard

Acquires a shared residency record for an engine mesh resource. Multiple scene objects using the same content revision receive the same generation-checked geometry handle. Reloading publishes a new record; outstanding references retain the previous revision. Mesh LODs packed into one buffer are translated into reflected meshlet ranges by the subsystem. Call on the render thread, as with other residency mutations. Returns an invalid handle for unloaded data.

xiiArrayPtr< xiiUInt32 > out_counts,
xiiUInt32 * out_pRootMeshlets = nullptr )
staticnodiscard

Counts meshlets overlapping a primitive range in each authored LOD, including unloaded LODs. A zero primitive count selects the entire LOD, matching GPU visibility. The output must have s_uiMaxLods entries and is cleared on failure. Builds a revision-owned interval index once, then counts exact overlaps in O(LODs * log(meshlets)). Rejects reloaded source buffers belonging to a different revision. Call on the render thread.
