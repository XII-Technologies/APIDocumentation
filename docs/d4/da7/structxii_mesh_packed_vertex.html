Detailed Description

Full fidelity authoring vertex used by AddCommonStreams() and geometry conversion.

The renderer is expected to read the declared stream layout. Mesh shader paths usually bind this as a structured SRV, while fallback vertex pipelines can bind the same buffer as a vertex buffer.
