Detailed Description

Packed, derived GPU draw data for one world. Has no object authoring, hierarchy or transform propagation API. Only extraction changes membership; world/component handles remain authoritative. Update and borrowed reads require the owning world's CPU extraction boundary. Graph callbacks copy their required upload bytes so they never access mutable world/component storage.
