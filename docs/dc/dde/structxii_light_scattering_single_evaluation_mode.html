Detailed Description

The method to use for evaluating a single light scattering.

Member Enumeration Documentation

◆ Enum

enum xiiLightScatteringSingleEvaluationMode::Enum : StorageType
Enumerator
None 

Do not evaluate light scattering. This can be useful for debugging and artistic purposes.

Integration 

Evaluate light scattering by integrating the scattering along the view ray, which is the standard method for evaluating light scattering and can produce high quality results with enough samples.

LookupTable 

Evaluate light scattering by sampling from a precomputed 2D lookup table based on the view zenith angle and the sun zenith angle, which can be much faster than integration but also less accurate and with limited artistic control.
