Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Compacts supplied meshlet work using LOD routing, primitive ranges, frustum and cone tests. InitialCount/InitialOverflow must be zero. Consumers must handle VisibleMeshletOverflow.
