Detailed Description

Route only events from the context's own host window, before BeginFrame. Never reads merged global input. Event methods support editor/Qt hosts; UpdateFromDevice supports XII windows. Text is explicitly supplied by subscribing to the source device's GetTextInputEvents(), preserving Unicode bursts and source identity.
