An Engine for Real-Time Simulations

XII provides the systems needed to build demanding real-time software without requiring every application to adopt the same stack. Graphics, simulation-oriented systems, resource management, and native tooling are organized into a unified, modular architecture.

Use XII as a complete engine, or integrate selected components through dynamically linked libraries. From interactive tools to specialized simulation workloads, the architecture is designed to give developers control over what they build and what they include.

Core capabilities

Real-time graphics

A modern graphics foundation with Vulkan and Direct3D 12 backends, designed for rendering and GPU-focused applications.

Modular architecture

Use the full engine or assemble a focused runtime from independently integrated engine components.

Simulation & interactivity

Systems for interactive applications, real-time simulation, and visualization workflows.

Native development tools

C++23, CMake-based project generation, resource workflows, and shader compilation tooling for DXIL and SPIR-V.
