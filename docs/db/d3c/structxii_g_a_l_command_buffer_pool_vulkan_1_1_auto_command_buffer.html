Detailed Description

RAII handle for a VkCommandBuffer allocated from this pool. On destruction: if not submitted, returns it immediately to free-list. If submitted via xiiGALCommandBufferPoolVulkan::RecycleAfterSubmit, the command buffer is moved out and not auto-recycled.
