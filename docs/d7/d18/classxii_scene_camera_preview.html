Detailed Description

A scene viewport's selected-camera preview. Owns an independent world-local view, camera and 256x144 render target; pipeline definitions are shared through the viewport's resource handle. Uses the regular native rendering pipeline and debug overlay, without an extractor or global render-target resource. The overlay samples the most recently rendered preview (initially black). Must be destroyed before its world. Call SuspendRendering() when consuming the viewport's redraw.
