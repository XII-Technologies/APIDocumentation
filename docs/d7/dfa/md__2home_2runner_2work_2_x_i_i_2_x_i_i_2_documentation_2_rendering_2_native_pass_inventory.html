State ownership

  • WorldInstancesUpload publishes the existing world's sparse instance/pose uploads. Repeated occurrences use the same graph upload and buffer versions. No hierarchy, scene object registry or transform propagation is added.
  • InstanceCull applies supplied flags, masks, frustum and residency tests and writes generation-validated LOD selections. LodHistoryReset initializes every entry on the GPU, including unselected/empty candidates. Neither consumes live world state.
  • MeshletDispatchBounds reduces the selected, generation-validated LODs on the GPU; MeshletDispatch creates indirect compute dimensions without a CPU count readback. MeshletCull compacts supplied work into graph-owned pairs, using primitive ranges, conservative transformed/posed bounds and eligible normal cones. Its own reflected budget controls physical allocation. The count saturates at capacity and a required overflow output reports dropped work; consumers must provide an explicit overflow policy. No renderer silently treats an overflowed list as complete.
  • VertexPullDrawCommands converts the supplied compact meshlet list into portable DrawIndirect arguments and an explicitly bounded indirect count. Residency metadata and primitive ranges are validated before a candidate emits work. It owns no rasterization, shader asset residency, scene lifecycle or CPU count readback.
  • SurfaceRasterConstants captures an immutable current-view snapshot and device table bases. SurfaceQuery consumes that uniform buffer and explicit draw/count buffers, emits one managed raster operation, and publishes surface identity/depth/normal data plus the nearest depth texture. Shader selection is an explicit reflected property; unsupported mesh shading fails rather than changing the authored path.
  • BufferHistory retains structured GPU buffers in completion-checked private slots, publishes explicit previous-frame pins and declares GPU readiness waits.
  • VisibilityView captures camera/frustum and selected component indices during setup. Execute consumes owned immutable frame data. Its parameters belong to each reflected occurrence. LOD tokens advance with that occurrence, including across interleaved device frames from other worlds.
  • GeometryUpload and MaterialUpload publish the existing device residency services. They allocate no world-specific copies of shared mesh or material assets.
  • CounterReset creates one graph-owned counter with a reflected initial value; visibility and indirect work can compose independently initialized counters.
  • BRDFLut requests the device-shared immutable lookup only when present. Generation signals a GPU fence; subsequent consumers declare device-side readiness waits.
  • ViewRenderResourceManager now owns pipeline instances directly. There is no hidden rendering runtime or automatically created lighting context behind a view.

Screen irradiance, refraction and immutable atmospheric application

Three focused operations replace five obsolete screen-effect passes. ScreenIrradianceTrace only gathers incident irradiance from supplied depth, normal, radiance and exact camera constants. ScreenRefractionTrace only samples background radiance and emits authored transmission in alpha. AtmosphereApply applies supplied LUTs and physical parameters to an immutable scene image. Every resource pin is a typed reflected member; every algorithm setting is an ordinary reflected member property. None has stage/technique selection or a hardware-GI presence check, and none requires material, geometry or light extraction merely because it exists.

ScreenIrradianceTrace retains the existing cosine-weighted Halton sampling and depth-march hit convention, while making sample/step counts, length, thickness, sequence offset and queue preference explicit. It emits E = pi * average incident radiance; screen-space misses stay black. Material response is independently evaluated by DiffuseSurfaceLighting, whose Lambertian division by pi recovers the old diffuse estimator. Transmission, metallic fraction, albedo and authored occlusion now consistently belong to that response operation. The graph supplies an explicit zero ambient coefficient so incomplete screen-space hits cannot accidentally add an ambient baseline. A zero ray length emits zero irradiance for valid depth without conditionally constructing another technique. No monolithic per-frame global settings buffer is required for gathering.

ScreenRefractionTrace reads immutable depth/normal/material/transmission/background images. It preserves projected-normal UV perturbation, depth scaling, maximum offset, chromatic spread and foreground rejection. The output is straight sampled radiance with transmission alpha, independent of the current foreground scene. ScreenRefraction wires that output through ConfidenceRadiance and RadianceAdd. Its foreground and background inputs may be different resources. Because the trace never writes its inputs, the old pre-refraction snapshot/copy operation is unnecessary and physically deleted. Existing foreground specular and emission remain in the foreground graph input.

AtmosphereApply preserves the existing spherical segment integration, Rayleigh/Mie phases, LUT sampling, solar disk and finite-distance aerial perspective. It consumes the narrow 48-byte EnvironmentLight contract, exact camera and atmosphere uniforms, depth and LUTs. It allocates a separate RGBA32Float result and preserves scene alpha on geometry, with alpha one for sky. LUT extents are independent from view extents. Its queue preference is reflected; the algorithm has no world-property lookup during execution. The existing AtmosphereConstantsPass remains the optional boundary for component-authored parameters. All three recorded operations retain GPU pipelines, samplers, copied options and explicit graph bindings, surviving pass retirement without mutable component references.
