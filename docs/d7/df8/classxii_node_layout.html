xiiResult xiiNodeLayout::Compute ( xiiArrayPtr< const QRectF > bounds,
xiiArrayPtr< const xiiNodeLayoutConnection > connections,
xiiDynamicArray< xiiVec2 > & out_positions )
static

Returns bounding-box top-left positions in input order. Input order is the stable tie-breaker; callers should sort nodes by persistent identity. Original positions only determine the anchor. Cycles share a column; disconnected components are packed separately. Invalid input fails with empty output. Repeated layout with unchanged sizes/connectivity is idempotent.
