xiiResult xiiAnimationPose::BuildMeshSkinningPalette ( const xiiSkeletonResource & skeleton,
const xiiMeshResourceDescriptor & mesh,
xiiDynamicArray< xiiMat4 > & out_palette,
xiiDynamicBitfield & inout_usedSlots ) const

Copyright (c) Theophilus Eriata. All Rights Reserved.

Resolves mesh bone names to joints and writes mesh-indexed matrices using the mesh's inverse bind poses. Empty bone maps use the skeleton palette. Sparse unused slots are identity. Invalid mappings/matrices fail and clear output. Requires model transforms for this skeleton revision. Output and scratch capacity are reused between calls. The output must not alias any of this pose's arrays.

Copies local joint transforms by name. Rejects mismatched counts, duplicate/empty names and invalid transforms. Clears the output on failure. The caller must ensure the pose belongs to this skeleton revision.
