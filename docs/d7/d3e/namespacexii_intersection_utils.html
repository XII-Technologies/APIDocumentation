bool xiiIntersectionUtils::RayPolygonIntersection ( const xiiVec3 & vRayStartPos,

float * out_pIntersectionTime = nullptr,
xiiVec3 * out_pIntersectionPoint = nullptr,
xiiUInt32 uiVertexStride = sizeof(xiiVec3) )

Checks whether a ray intersects with a polygon.

The vertex winding order does not matter, polygons will be hit from both sides.

Parameters
vRayStartPosThe start position of the ray.
vRayDirThe direction of the ray. This does not need to be normalized. Depending on its length, out_fIntersectionTime will be scaled differently.
pPolygonVerticesPointer to the first vertex of the polygon.
uiNumVerticesThe number of vertices in the polygon.
out_fIntersectionTimeThe 'time' at which the ray intersects the polygon. If vRayDir is normalized, this is the exact distance. out_fIntersectionPoint == vRayStartPos + vRayDir * out_fIntersectionTime This parameter is optional and may be set to nullptr.
out_fIntersectionPointThe point where the ray intersects the polygon. out_fIntersectionPoint == vRayStartPos + vRayDir * out_fIntersectionTime This parameter is optional and may be set to nullptr.
uiVertexStrideThe stride in bytes between each vertex in the pPolygonVertices array. If the array is tightly packed, this will equal sizeof(xiiVec3), but it can be larger, if the vertices are interleaved with other data.
Returns
True, if the ray intersects the polygon, false otherwise.
