Detailed Description

Unit-safe photometric conversions used by components, GPU extraction, and sensor rendering. All inputs are clamped to finite, non-negative values.

Converts an authored distant-light value to canonical illuminance. Nits are integrated over the apparent source solid angle. Candela and lumen inputs are interpreted at a calibration distance of one metre.
