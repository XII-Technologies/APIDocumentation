Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Filters supplied absolute (instance, meshlet) pairs against a matching reversed-Z depth image and projection. Temporal validity/invalidation belongs to the graph supplying those explicit inputs. InitialCount must contain zero; this operation owns no scene state or history.
