Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Physical quantity used to author the intensity of a light source.

The renderer converts authored values to the canonical quantity required by each emitter: candela for local lights, lux for directional lights, and nits for finite area emitters.
