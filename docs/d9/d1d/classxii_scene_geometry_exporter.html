Detailed Description

Exports native mesh components as OBJ triangle geometry, without creating a rendering pipeline. Includes LOD zero, selected sections, local instances and current skinning matrices. OBJ output contains positions and faces; materials, UVs and normals are not exported. GPU-only geometry is read back synchronously, so this operation belongs on the engine-process thread between frames. The caller must hold the world's write marker. Empty selection exports no objects when bSelectionOnly is true. Editor-tagged and inactive objects are excluded. Validation failures discard the pending output before opening the destination. Final disk writes use xiiDeferredFileWriter and report I/O failures; this writer does not guarantee atomic replacement against disk failure. Collision providers use Core's xiiMsgBuildStaticMesh world-space description. Navmesh export requires the native geometry module and supports whole-world queries only, since its interface has no object IDs.
