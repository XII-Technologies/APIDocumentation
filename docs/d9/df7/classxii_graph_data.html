template<typename VertexData, typename EdgeData>
class xiiGraphData< VertexData, EdgeData >

Copyright (c) Theophilus Eriata. All Rights Reserved.

Typed, owning property maps attached to an existing graph. Payloads may be values, pointers or engine smart pointers. Missing properties are allowed. Removed elements and topology replacement automatically destroy their properties. The graph must outlive this object. Property pointers are transient across changes to their property map. No virtual node base, void pointers, reflection requirements or per-element allocations are imposed.
