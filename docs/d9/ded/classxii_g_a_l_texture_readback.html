xiiResult xiiGALTextureReadback::Enqueue ( xiiGALCommandList * pCommandList,
const ReadbackRequest & request )

Enqueue a readback from a texture into an internal staging texture.

Records copy commands on the provided command list and signals an internal fence. Failure rejects invalid subresources/regions or unavailable staging/fence resources without recording a copy or adding a pending capture. Supports single-sample, uncompressed 2D textures, 2D arrays and cube faces. The source and command list must belong to this helper's device.
