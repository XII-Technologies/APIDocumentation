Detailed Description

Subsystem-owned sparse hierarchy of bounded participating media.

World streaming marks cells resident or non-resident without invalidating stable medium handles. Per-view queries visit only overlapping resident cells, deduplicate volumes spanning multiple cells, and return a priority/distance sorted GPU working set.
