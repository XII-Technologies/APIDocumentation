Detailed Description

A concrete render graph profiler that uses GPU Duration queries.

Uses xiiGALQueryType::Duration to bracket each pass with BeginQuery / EndQuery. Results are read back with a configurable number of frames of delay (default: 2) to avoid GPU stalls. Up to xiiRenderGraphTimestampProfiler::MaxTrackedPasses distinct pass names can be tracked simultaneously.
