Detailed Description

Copyright (c) Theophilus Eriata. All Rights Reserved.

Immutable GGX radiance and Lambert irradiance derived from one resident cubemap. Creation runs on the thread owning the active xiiRenderGraphFrame and submits initialization once. Every consuming queue must wait for m_Ready (value 1).
