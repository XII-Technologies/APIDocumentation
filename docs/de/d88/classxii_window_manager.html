Detailed Description

Manages registered windows and their associated data.

The WindowManager provides a centralized system for managing windows throughout their lifetime. Windows are registered with unique handles and can have associated output targets and destruction callbacks.

Closes and unregisters a specific window.

This first calls any registered destroy callback, then destroys the output target, then the window. The handle becomes invalid after this call.
