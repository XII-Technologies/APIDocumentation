Detailed Description

Iterative algorithms over xiiGraph's public connectivity interface. No recursion or permanent graph bookkeeping. Basic traversal/connectivity operations take O(V + E) time and O(V) auxiliary space; optimizations specify their bounds below. Outputs are replaced, retaining their allocations. Pass a workspace to reuse temporary allocations too. Without one, scratch uses the default allocator. The graph must remain unchanged throughout each call.

Visit start and its reachable successors, following outgoing edges. Other components are not visited. Breadth first visits by nondecreasing distance; depth first visits in preorder. Adjacency is newest first. An invalid/foreign start or empty visitor returns XII_FAILURE without invoking the visitor.

Kahn's algorithm. Includes isolated vertices and disconnected components. Source precedes target for every edge. Returns XII_FAILURE and clears output on any cycle (including self-loops). Empty graphs succeed. Ready vertices use FIFO order seeded by GetVertices(); ties are otherwise unspecified.
