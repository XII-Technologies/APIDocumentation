enum xiiGALRayTracingInstanceFlags::Enum : StorageType
Enumerator
None 

No instance flags are set. Triangles use clockwise winding for front-facing determination, and ray-specified front/back-face culling is permitted.

TriangleCullDisable 

Disables front- and back-face culling for triangles in this instance. Ray flags requesting front- or back-facing triangle culling have no effect.

TriangleFrontCounterClockwise 

Treats counter-clockwise triangles as front-facing. By default, clockwise triangles are considered front-facing.

ForceOpaque 

Forces all geometries in this instance to be treated as opaque, overriding their per-geometry opaque state unless overridden by a ray flag.

ForceNonOpaque 

Forces all geometries in this instance to be treated as non-opaque, overriding their per-geometry opaque state unless overridden by a ray flag.
