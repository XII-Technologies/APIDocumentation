Detailed Description

Converts per-queue GAL fence progress into a conservative completed-frame index.

CaptureSubmittedFrame() is called after every queue submission belonging to a frame. PollCompletedFrames() advances only when every unique queue used by that frame has completed the value captured for it. The result is safe for deferred destruction, bindless index recycling, streaming eviction, and frame-ring reuse. Frame indices start at one; zero is reserved as the conservative "none completed" value.
